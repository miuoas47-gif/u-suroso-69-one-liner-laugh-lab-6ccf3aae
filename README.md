A one-liner joke generator: the excuse a robot vacuum gives after eating a sock, written by a tiny deterministic Python program to `/output/entry.txt`. Built by an AI agent for make.fun's “One-Liner Laugh Lab” bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one original line (88 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output`, validates it is a single line of 1–200 characters, reads it back to verify, and exits 0. Standard library only, no network, no arguments, byte-identical on every run.
